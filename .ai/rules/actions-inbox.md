# Actions Inbox

## Inbox media slots: copy once, keep the copy on re-reads
Every inbox file a network links is copied into our storage (owner decision 2026-10-17: avatars, DM photos, every media case, on every network): any http(s) link not already under the default disk's URL (InboxMediaSlots::isNetworkHosted, Storage::url('')) is copied; there is no host list. Only the SSRF guard, the type and the size limits refuse a file. Rows store only paths on our disk (owner decision 2026-10-17): author_avatar_path, media.N.path/thumbnail_path, meta.content.path/thumbnail_path; participant_avatar_path, subject_media.N.*; resources build the URLs with Storage::url and keep the client's field names (avatar_url, url, thumbnail_url). A network link is never rendered: InboxMediaSlots::fromNetwork() leaves the slot empty and parks the link in meta.pending_media until StoreInboxMediaJob (media-imports, unique, 3 tries) copies it; meta.stored_media records each handled slot (':' for dots -> media id, or 'unstored', which stays empty and is never retried). keepStored() keeps a copy when a re-read brings the same item with a freshly signed link. A shared post's meta.content.url is a link to the post, kept as is; only its thumbnail is copied. Messages the channel wrote (outbound: replies, DMs, own comments read from the network) store no avatar at all: the resource shows the channel's current avatar. Inbound DMs store no avatar either: every inbound bubble of a DM conversation shows the conversation's participant_avatar_path (InboxMessageResource, conversation read once per request). One InboxUpdated per row write. Backfill: inbox:store-media.

## Inbox counts: page follows the range, sidebar badge does not
CountOpenInboxMessages without a range reads the cached conversations.open_count (the global sidebar badge, HandleInertiaRequests: everything open). With a DateRange it counts open inbound messages written since range->since(); BuildInboxPageProps passes the filter's range for tabCounts and inboxChannels.*.open_count so they match the List view. DM conversations expose `resolved` (every inbound resolved, via InboxConversation::unresolvedInboundCheck() withExists/loadExists in ListInboxConversations (Messages tab) and ShowInboxConversation). The List view takes `messages_around` (ListInboxMessages::pageOf) like `thread_around`.

## Comments always belong to an imported post; one write path
Owner decision 2026-10-17. Polls and Meta webhooks reach the inbox only through UpsertInboxMessages. A Comment whose post is not in posts is parked (ParkInboxMessages → inbox_pending_messages, unique per message) and ImportInboxPost imports it (ImportInboxConversationPost: existing post, else publication by social_account_key+remote_id, else the poll's DiscoveredPublication, else FindsPublication::find on Meta collectors; then ImportExternalPosts::importPublication + ImportExternalPostMedia), retrying BACKOFF and giving up after MAX_ATTEMPTS (dismissed posts give up at once). Comment conversations store no subject_* (InboxConversation::subject() reads the post); mentions keep their snapshot. Webhook messages carry observedAt (event time): an older delivery never overwrites a newer one; a removal before its message leaves a cache tombstone (RemoveInboxMessages::wasRemoved).

## Comment score: definitions, cache, surfaces
Owner-approved defaults (2026-10-18). CalculateInboxScore: window = the last 7 local days of the viewing user's zone (today included); counts inbound, not removed messages of Comment/Review conversations (visibleInTab Comments: no mentions, no DMs) in the channels in scope. Response rate = answered (answered_at set; resolving without a reply does not count) / inbound, capped at 20% for 1–4 comments and 60% for 5–9. Speed = average per answered comment: 100% when answered_at − platform_created_at ≤ 2 h, linear to 0% at 48 h. Consistency = days with inbound where one of that day's comments was answered the same local day / days with inbound. Score = round(0.5·rate + 0.3·speed + 0.2·consistency); levels ScoreLevel (0–20, 21–40, 41–60, 61–80, 81–100). No inbound in the window → score/level/metrics null (badge "–"). Day buckets are CASE expressions with UTC day bounds in InboxMessage::scopeSelectScoreTotals (never CONVERT_TZ); speed reads only the answered pairs. cached() keys workspace + version + zone + local day + channel scope for 10 min; ForgetInboxScore (InboxUpdated listener) bumps the version. Surfaces: web deferred prop `commentScore` (in INBOX_RELOAD_KEYS), GET api.inbox.score.show, get-inbox-score-tool [true,false,false]; parity in tests/Feature/Parity/InboxScoreParityTest.php. Every part (badge, gauge and bars) follows the channel filter and the title names the channel when one is picked.
